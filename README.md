# Deep Learning Techniques for Financial Fraud Detection: A Review

## Project Overview
This project presents a literature review of deep learning techniques used for financial fraud detection.

## Topics Covered
- Transformer-based models
- Graph Neural Networks (GNNs)
- Autoencoders
- Financial fraud detection datasets
- Evaluation metrics and research challenges

## Repository Structure
- `Report/` – Final survey paper
- `Research/` – Literature matrix and reference library
- `Figures/` – Research diagrams and charts
- `Annexure/` – Search log and declarations
